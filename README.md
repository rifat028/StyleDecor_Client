# 🏡 StyleDecor – Smart Home & Ceremony Decoration Booking System

## 📌 Project Overview

StyleDecor is a modern web-based appointment and service management system designed for decoration companies. It allows users to explore decoration services, book consultations or on-site services, make payments, and track project progress in real-time.

This platform solves common problems in local decoration businesses such as manual booking, poor scheduling, and lack of service tracking by offering a complete digital solution.

## ✨ Core Features

### 👤 User Features

- Browse decoration services and packages
- Search & filter services by category and price
- Book consultation or on-site services
- Secure online payment system
- Track booking status in real-time
- View booking history and payment records

### 🧑‍💼 Admin Features

- Manage services and decoration packages (CRUD)
- Manage decorators and users
- Assign decorators to projects
- Monitor revenue and analytics
- Approve or disable decorator accounts

### 🎨 Decorator Features

- View assigned projects
- Update project status step-by-step
- Manage daily schedule
- Track earnings summary

### 🔥 Additional Features

- Role-based dashboard (User/Admin/Decorator)
- JWT protected routes
- Dynamic service listings
- Responsive UI design
- Toast notifications & loaders
- Service coverage map integration
